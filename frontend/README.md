# Support Ticket Frontend

React + Vite UI for the Support Ticket Management System.

## Setup

```bash
cp .env.example .env
npm install
npm run dev
```

`VITE_API_BASE_URL` must point at the running backend (default `http://localhost:8080`).

## Scripts

- `npm run dev` — local development server (port 5173)
- `npm run build` — production build
- `npm test` — unit tests (Node.js test runner)
