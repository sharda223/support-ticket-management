# SpecStory history

This directory exists to satisfy the assignment’s expected `.specstory/history/` location for AI prompt history.

## Where prompt history lives

Exact historical Cursor/SpecStory transcript export is **not available** in this repository.

The real Spec-Driven Development prompt workflow for this project is documented in:

**[`docs/prompt-history.md`](../../docs/prompt-history.md)**

That document distinguishes:

- **Exact** prompts recovered from the Cursor agent transcript
- **Reconstructed** process summaries (tools/outcomes) where only evidence of work exists

## What is intentionally not here

- No fabricated Cursor conversation files
- No fake SpecStory JSON/Markdown prompt dumps
- No invented timestamps or AI replies presented as raw history

If a real SpecStory (or similar) export becomes available later, it can be placed in this directory without changing application source code.
